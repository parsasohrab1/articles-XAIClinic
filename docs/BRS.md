# Business Requirements Specification – XAIClinic

| ID | Requirement |
|----|-------------|
| BR-1 | Quantify how much the top-k important features of a clinical classifier change when the training set is resampled. |
| BR-2 | Compare explanation methods (standardised absolute logistic coefficients, permutation importance, random-forest Gini importance) on the same fits. |
| BR-3 | Report real-data results only and state when an explanation is not reproducible. |
| BR-4 | Make no claim on clinical validity of the highlighted features. |

Out of scope: causal interpretation, clinician user studies, imaging data.
